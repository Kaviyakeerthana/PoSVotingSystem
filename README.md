🚀 Proof of Stake-Based Voting System Using Blockchain

This project is a decentralized blockchain-based voting system that leverages the Proof of Stake (PoS) mechanism to ensure transparent, secure, and tamper-proof digital elections.

 🔑 Key Features:
 🧑‍💼 User Registration & Authentication:
  Users can securely sign up, log in, and register as voters using Aadhaar and MetaMask wallet address.

 ✅ Validator-Based Voter Approval: 
  -Voter registrations are verified by 3 validators. A minimum of 2 out of 3 approvals are required for a voter to be eligible.

 🏛️ Top Stake Validator Governance:  
  The validator with the highest stake is given special privileges to:
   -Add election candidates
   -Manage election phases (Registration → Voting → Result)

 🗳️ Secure Blockchain Voting: 
  -Approved voters can cast their vote through MetaMask, ensuring one person = one vote. All votes are recorded immutably on the Ethereum blockchain.

 📊 Live Result Viewing:  
  -During the Result Phase, voters can view transparent vote counts for all candidates directly from the blockchain.

🛠️ Tech Stack:
- Frontend: React.js, Tailwind CSS  
- Blockchain: Solidity, Ganache, Web3.js  
- Wallet Integration: MetaMask  
- Backend: Node.js + Express (for Aadhaar-based voter eligibility)  
- Database: MySQL (for storing registered users & Aadhaar mapping)

 🎯 Objective:
To provide a decentralized, transparent, and fraud-resistant voting system that eliminates the need for centralized authorities and promotes fair elections using blockchain and PoS consensus.
